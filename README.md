# BOD3D – Bag of Dungeon 3D

**Free to play. Open-source code. Make your own adventures.**

BOD3D is the official browser-based digital adaptation of **Bag of Dungeon**, created and maintained by **Gunpowder Studios Ltd**.

Play the official live version here:
https://gunpowderstudios.github.io/BOD3D/

## The official BOD3D

The official BOD3D game, its design direction and the live version are controlled and maintained by Gunpowder Studios.

The repository is public so players, developers and dungeon-builders can explore how it works, learn from it and create their own versions. A fork is a separate copy of the project: changes made in somebody else's fork do **not** change the official BOD3D game.

## Make your own adventure

Want to build a forgotten crypt, a goblin stronghold or an entirely new dungeon?

You are welcome to fork or download BOD3D and create your own **free, non-commercial community adventure**. Change the dungeon, encounters, monsters, quests, rules and code, then share your version with other players.

Community projects should be clearly labelled as unofficial fan-made adventures and credit:

> **Based on BOD3D / Bag of Dungeon by Gunpowder Studios Ltd.**

If you create a useful code improvement or bug fix that you think belongs in the official game, you can also propose it back to us through a GitHub pull request. Gunpowder Studios decides what is included in the official version.

## About Bag of Dungeon

Bag of Dungeon is an old-school fantasy dungeon-crawling board game by Gunpowder Studios. Every dungeon is different: explore, fight monsters, find equipment and try to escape alive with the treasure.
